type, public :: nurbs_multipatch_curve

Ordered collection of connected NURBS curve patches.

Valid side labels accepted by connect are left, right, min, and max (case variants shown in the implementation are accepted). continuity=-1 retains an interface without continuity equations; continuity=0 merges matching endpoint degrees of freedom; higher orders additionally appear in the sparse constraint matrix.

Diagnostic codes are: 201 invalid patch identifier; 202 invalid side; 203 invalid continuity metadata; 204 incompatible interface geometry or trace space; and 205 invalid patch state.

procedure, public :: connect => connect_curve

Validate connection metadata and record an oriented endpoint interface.

  • private pure subroutine connect_curve(this, patch_a, side_a, patch_b, side_b, continuity, reverse, geometric, reparameterization)

    Author
    Seyed Ali Ghasemi
    License
    BSD 3-Clause

    Record two curve endpoints with parametric or geometric metadata. continuity defaults to zero and geometric defaults to .false.. A G^n connection requires reparameterization(k) to contain the kth derivative of patch B's normalized parameter with respect to patch A's normalized local parameter at the interface. The scalar transition is the complete local reparameterization model for a curve endpoint. reverse has no mathematical effect because an endpoint has no tangential coordinate; it is stored only for API symmetry.

    Read more…
