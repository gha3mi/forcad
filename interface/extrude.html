extrude_curve extrude_surface

public interface extrude

Construct a degree-one extrusion of a curve or surface.

Curve input returns a surface; surface input returns a volume. The source directions are copied exactly and the new direction has knot vector [0,0,1,1], degree one, and no parameter wrapping.
