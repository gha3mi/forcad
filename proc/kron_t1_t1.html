private pure function kron_t1_t1(u, v) result(w)

Form the Kronecker product of two vectors.

The result is ordered in blocks of v: w((i-1)*size(v)+j)=u(i)*v(j).

Arguments

Type IntentOptional Attributes Name
real(kind=rk), intent(in), contiguous :: u(:)

Left vector.
real(kind=rk), intent(in), contiguous :: v(:)

Right vector, varying fastest in the result.

Return Value real(kind=rk), (size(u)*size(v))

Kronecker product of length size(u)*size(v).
