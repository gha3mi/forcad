public pure subroutine rotate_points(points, n, alpha, beta, theta)

Rotate the first n rows of a point array in place.

The same Euler convention as rotation is used. Arrays with at least three coordinates rotate their first three and leave additional coordinates unchanged. One- and two-coordinate arrays receive only the leading principal submatrix of the three-dimensional rotation; that map is not generally an orthogonal lower-dimensional rotation when omitted coordinates couple to the selected angles. n is clipped to the available rows; a negative n changes nothing.
