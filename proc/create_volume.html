private pure subroutine create_volume(this, res1, res2, res3, Xt1, Xt2, Xt3, Xt)

Sample every volume patch with common directional sampling arguments. Arguments are forwarded unchanged to create. Any patch failure is converted to multipatch diagnostic code 205.
