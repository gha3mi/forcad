Fit polynomial tensor-product B-spline control points to parameterized data.

ndata=[n1,n2] defines the number of rows used. For a recognized direction-1-fastest Cartesian parameter grid, Kronecker separability is exploited through two directional banded normal-equation solves. The grid test requires exactly product(ndata) parameter and data rows and compares repeated directional coordinates with tolerance 32*epsilon(rk)*max(1,maxval(abs(Xt))). Otherwise the first product(ndata) rows use one banded tensor-product normal equation.

The fit uses the polynomial tensor basis even if explicit weights are stored; it neither reads nor clears those weights. Thus this%is_rational() must be false if later object evaluation is to match the fitted objective. Xt and Xdata must provide enough finite rows, Xt must have at least two columns, Xdata at least one, and each directional parameter set must give full-rank active-domain coverage. These shape and finiteness preconditions are not completely diagnosed. Only Xc is replaced; cached Xg is not recomputed.

Warning

Both paths use normal equations and require full-rank, well-scaled parameter coverage; no QR or SVD fallback is performed.
