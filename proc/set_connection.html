private pure subroutine set_connection(this, patch_a, side_a, patch_b, side_b, continuity, reverse, swap, flip, geometric, reparameterization)

Store low-level connection metadata and reset omitted options to defaults.

Warning

This routine performs no patch-level validation. Rank-specific connect methods should be used for normal construction.
