private pure subroutine derivative_order_vector(this, order, Dgc, res, Xt)

Compute one requested derivative order at a vector of curve parameters. The dense result satisfies Dgc(g,i)=d**order R_i(Xt(g))/du**order. Explicit Xt replaces the parameter cache; otherwise positive res generates an inclusive active- interval grid, and with neither argument the existing cache is reused. The method updates ng and the parameter cache but does not recompute cached geometry Xg. Nonfinite explicit parameters are not diagnosed by this overload and produce zero basis rows when they cannot select a span.
