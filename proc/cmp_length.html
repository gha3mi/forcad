private pure subroutine cmp_length(this, length, ngauss)

Integrate arc length over all nonzero active knot spans.

The computed approximation is

Each nonzero active span uses an independent Gauss-Legendre rule, so repeated knots do not bridge elements. Degenerate tangents contribute zero measure at the affected quadrature points. Although an -point Gauss rule is exact for polynomial integrands through degree , the arc-length integrand is generally nonpolynomial, including for a polynomial spline curve; this method therefore provides numerical quadrature rather than an exact-length guarantee.

A valid initialized curve and ngauss>=1 are caller preconditions; the latter is not diagnosed here. If an existing diagnostic is active, the routine returns length=0 without integration.
