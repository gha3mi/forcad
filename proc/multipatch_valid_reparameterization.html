public pure function multipatch_valid_reparameterization(connection, normal_sign) result(ok)

Validate the transition jet for a parametric or geometric connection. For , reparameterization(k) is in the scalar normal-only model documented by this module. For n>0, the array must have exactly n finite entries and its first derivative must satisfy normal_sign*reparameterization(1)>sqrt(tiny(1.0_rk)). For n=0, the array must be absent or empty. Higher entries are otherwise unconstrained; any finite jet with an accepted first derivative defines a local scalar diffeomorphism jet, but this routine does not validate a more general multivariate reparameterization.
