private pure subroutine cmp_area(this, area, ngauss)

Integrate physical surface area over all nonzero knot-span cells. For a two-coordinate mapping the measure is the absolute determinant of its Jacobian. For every other embedding dimension, the measure is ; fewer than two independent tangent directions are consequently diagnosed as singular. The approximation is

A separate tensor Gauss-Legendre rule is used on every nonzero active knot-span cell. The metric measure is generally nonpolynomial, so the default degree+1 rule is an approximation and not an exact-area guarantee. A quadrature point is treated as singular when the determinant test in the implementation falls below a 64*epsilon(rk) relative scale; code 108 is set and that point's contribution is omitted from the partial result.

A valid initialized surface and positive entries of ngauss are caller preconditions; quadrature counts are not diagnosed here. If an existing diagnostic is active, the routine returns area=0.
