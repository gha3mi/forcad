private pure function cmp_elem_curve(this, shared) result(elem)

Concatenate active-span element connectivity from all patches.

Rows follow patch insertion order and then each patch's span order. Columns are padded with zero when patch degrees differ. By default node identifiers use unmerged patch offsets; with shared=.true., the result uses compact identifiers from cmp_dof_map.
