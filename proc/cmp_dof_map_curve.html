private pure function cmp_dof_map_curve(this) result(map)

Build compact global identifiers for topologically shared endpoints.

The input position is the unmerged index defined by cmp_dof_offsets. Connections with continuity at least zero merge their paired boundary controls. Higher derivative conditions are not eliminated here; use cmp_dof_constraint. This method trusts recorded topology and does not call is_valid.

Disjoint-set implementation reference: R. E. Tarjan, "Efficiency of a Good But Not Linear Set Union Algorithm," JACM 22 (1975), 215--225. doi:10.1145/321879.321884.
