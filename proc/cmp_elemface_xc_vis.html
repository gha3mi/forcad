private pure function cmp_elemFace_Xc_vis(this, elem, face) result(elemConn)

Extract one quadrilateral face from a control-lattice VTK cell.

elem selects a stored visualization cell. Face numbering is [w_min,w_max,v_min,v_max,u_min,u_max]. The result has four global point indices, or is empty for invalid or unavailable state. number of nodes in each direction
