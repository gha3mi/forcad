private pure function cmp_elem_Xc_vis(this, p) result(elemConn)

Build structured quadrilateral connectivity for the control net.

Optional p=[p_1,p_2] selects the visualization cell order; the default is bilinear. Numbering follows direction-1-fastest storage.
