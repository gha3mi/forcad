public pure recursive subroutine insert_knot_A_5_1(p, UP, Pw, u, k, s, r, nq, UQ, Qw, T)

Insert a knot without changing the represented homogeneous geometry.

For s+r<=p, this is Algorithm A5.1 of Piegl and Tiller, equivalent to repeated Boehm knot insertion. The s+r=p+1 extension first applies the standard insertion through multiplicity , then duplicates the interface control row to represent the same two one-sided pieces in a discontinuous space. Arrays use the algorithm's zero-based bounds. When requested, T satisfies Qw=matmul(T,Pw) and can transform any field in the same spline space. r=0 returns the exact identity operation.
