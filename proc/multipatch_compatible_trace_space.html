public pure function multipatch_compatible_trace_space(knot_a, nc_a, degree_a, knot_b, nc_b, degree_b, reverse, tol) result(ok)

Test whether two normalized univariate trace spaces coincide.

Degrees and control counts must match. Knot arrays are assumed to be valid for the supplied degrees and counts. Values are compared after an affine map from each active interval to ; reverse compares the second trace in opposite orientation. Multiplicities are therefore preserved by the entrywise comparison.
