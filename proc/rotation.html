public pure function rotation(alpha, beta, theta) result(R)

Return an active right-handed Euler rotation matrix.

Angles are in degrees and acts on column vectors. Thus the active rotations are applied successively about the fixed x, y, and z axes (the extrinsic xyz convention).

Arguments

Type IntentOptional Attributes Name
real(kind=rk), intent(in) :: alpha

Rotation about the x axis in degrees.
real(kind=rk), intent(in) :: beta

Rotation about the y axis in degrees.
real(kind=rk), intent(in) :: theta

Rotation about the z axis in degrees.

Return Value real(kind=rk), (3,3)
