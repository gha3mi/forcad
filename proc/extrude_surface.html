private pure function extrude_surface(surface, vector) result(volume)

Extrude a NURBS surface exactly into a degree-one tensor-product volume.

Source directions 1 and 2 are copied unchanged. Direction 3 uses [0,0,1,1], and the second control layer is translated by vector. The construction is exact because both layers retain the source weights.

Arguments

Type IntentOptional Attributes Name
type(nurbs_surface), intent(in) :: surface

Valid source surface.
real(kind=rk), intent(in), contiguous :: vector(:)

Finite, nonzero extrusion vector. Its size determines the output coordinate dimension and must be between the source dimension and three.

Return Value type(nurbs_volume)
