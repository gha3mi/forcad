private pure subroutine compute_d2Tgc_bspline_1d_scalar(Xt, knot, degree, nc, d2Tgc, dTgc, Tgc, wrap_parameters)

Evaluate dense polynomial curve basis values and first two derivatives.

Each allocated output has length nc; entries outside the active support are zero. Optional wrapping is applied before span selection.
