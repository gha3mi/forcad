private impure subroutine nearest_point2(this, point_Xg, tol, maxit, nearest_Xt, nearest_Xg)

Compute a continuous nearest-point candidate on the active curve domain.

Ten streamed parameter seeds choose an initial point. Bounded Newton iterations minimize ; a non-descent Newton direction is replaced by the negative gradient. The line search attempts at most 50 feasible Armijo reductions. At that cap the last feasible step can be accepted without a sufficient-decrease certificate. Termination occurs for the absolute gradient test, the absolute parameter-step test, or a numerically blocked feasible step; the last case does not by itself certify constrained stationarity. Consequently the output is a bounded local candidate, not a certified local or global minimizer. Failure to reach a stopping test within maxit sets code 109; a rejected scalar Hessian sets code 108. Once an iteration has been initialized, outputs contain its last defined iterate.

Line-search reference: L. Armijo, "Minimization of Functions Having Lipschitz Continuous First Partial Derivatives," Pacific Journal of Mathematics 16 (1966), 1--3. doi:10.2140/pjm.1966.16.1.
