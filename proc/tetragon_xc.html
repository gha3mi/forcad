public pure function tetragon_Xc(L, nc) result(Xc)

Generate a uniformly spaced planar rectangular control net.

L and nc must each have exactly two entries and every count must be greater than one; these shape preconditions are not checked. Coordinates run from zero to each signed extent and the third coordinate is zero.

Arguments

Type IntentOptional Attributes Name
real(kind=rk), intent(in), contiguous :: L(:)

Signed axis extents [Lx,Ly].
integer, intent(in), contiguous :: nc(:)

Directional point counts [nx,ny], each greater than one. The result has shape [product(nc),3], lies in z=0, and stores x/direction 1 fastest.

Return Value real(kind=rk), allocatable, (:,:)
