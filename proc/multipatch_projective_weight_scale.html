public pure subroutine multipatch_projective_weight_scale(Wa, Wb, tol, weight_scale, ok)

Test projective equivalence of two rational boundary weight vectors.

Homogeneous control data represent the same Euclidean geometry when all weights and weighted coordinates differ by one nonzero scalar. This routine checks only the weight part: it determines the candidate from the first weights and verifies componentwise. Coordinate compatibility must be established separately.
