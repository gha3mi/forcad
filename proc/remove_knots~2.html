private pure subroutine remove_knots(this, dir, Xth, r)

Attempt geometry-preserving removal of interior directional knots. Up to r(i) copies are attempted in array order. Xth(i) must equal an existing stored knot exactly and lie more than the current knot_tolerance from both active endpoints. The longest removable prefix is accepted; the first failed componentwise, roundoff-scaled control test ends that request. Rational data are tested in homogeneous coordinates, so the criterion is not a certified Euclidean geometry-error bound.

Algorithm: W. Tiller, Computer-Aided Design 24 (1992), 445--453. doi:10.1016/0010-4485(92)90012-Y. Applied directionally using Piegl and Tiller, Algorithm A5.8.
