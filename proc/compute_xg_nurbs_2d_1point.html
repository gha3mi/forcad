private pure function compute_Xg_nurbs_2d_1point(Xt, knot1, knot2, degree, nc, Xc, Wc, wrap_parameters) result(Xg)

Evaluate a rational surface at one parameter pair.

The result has length size(Xc,2). Optional wrapping is applied independently in both directions, and a zero weight denominator leaves the initialized result zero.
