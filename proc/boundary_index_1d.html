private pure subroutine boundary_index_1d(nc, side, reverse, idx)

Return the selected endpoint index of a one-dimensional control array.

Side 1 is the minimum endpoint and side 2 the maximum endpoint. Because an endpoint contains one index, reverse has no effect. An invalid side returns the sentinel array [0].

Arguments

Type IntentOptional Attributes Name
integer, intent(in) :: nc

Number of controls.
integer, intent(in) :: side

Endpoint identifier, 1 for minimum or 2 for maximum.
logical, intent(in) :: reverse

Orientation flag; immaterial for a single endpoint.
integer, intent(out), allocatable :: idx(:)

One-element endpoint index, or [0] for an invalid side.
