private pure function is_valid_curve(this, tol) result(ok)

Validate all patches and connection invariants without changing state.

Validation covers patch diagnostics, patch/side ranges, continuity order, endpoint-control coincidence, transition jets, homogeneous derivative residuals, and rational projective weight compatibility. tol is used as one absolute threshold for physical coordinates and assembled homogeneous residuals; the default is sqrt(epsilon(rk)). Specifically, paired coordinates and each component of are compared directly with tol. Weight proportionality uses max(tol,128*epsilon(rk))*max(abs(wA),abs(lambda*wB)) for each pair. tol>=0 is a caller precondition and is not separately diagnosed. The test conservatively requires both patches to have the same whole-patch is_rational classification and, for rational patches, enforces the constant-projective-scale homogeneous model documented by forcad_multipatch. It can therefore reject a Euclidean join admitted by a more general projective gauge.
