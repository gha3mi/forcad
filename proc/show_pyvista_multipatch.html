public impure subroutine show_pyvista_multipatch(vtkfile_Xc, vtkfile_Xg, vtkfile_Xth_in_Xg, rank_name)

Display previously exported multipatch VTK files using exact paths or glob patterns. Matching files are sorted before display so patch ordering is deterministic. This routine does not export geometry. Defining NOSHOW_PYVISTA at compilation makes it a no-op.
