private pure elemental function is_rational(this) result(r)

Report whether stored nonuniform weights affect basis evaluation.

With positive stored weights, the result is true precisely when

Weights within that threshold are evaluated through the polynomial path, not merely reported as approximately uniform. An active diagnostic or absent explicit weights returns false.
