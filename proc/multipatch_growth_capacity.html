public pure elemental function multipatch_growth_capacity(current) result(next)

Return the next geometric-growth capacity for patch metadata arrays. The result is at least 16 and doubles established capacities, giving amortized constant-time append without changing mathematical data.

Arguments

Type IntentOptional Attributes Name
integer, intent(in) :: current

Current allocation capacity; nonpositive values are allowed.
