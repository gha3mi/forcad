Numerical kernels and low-level geometry utilities used by ForCAD.

This module contains the public building blocks behind the single- and multipatch APIs. Real arguments use rk, and tensor-product indices are flattened with direction 1 varying fastest. Mathematical subscripts in this module are zero-based unless stated otherwise; Fortran array indices and returned connectivity are one-based. A documented mathematical precondition is not necessarily checked at run time: each procedure states whether an invalid input is represented by a sentinel result or must be excluded by the caller.

Despite its name, degree is the number of quadrature points minus one. Thus points integrate every univariate polynomial of degree at most exactly in exact arithmetic. Tensor products have this directional exactness separately in each coordinate.
