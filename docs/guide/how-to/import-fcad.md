title: Import an FCAD project
category: Projects and exchange

Use **Import FCAD** when the receiving model is already open and you want to add another project's objects to it.

1. Activate the destination project tab.
2. Choose **Project → Import FCAD** and open the source `.fcad` file.
3. Studio selects the imported objects and frames the selection when possible. Inspect them in **Scene**, then save the destination project.

To transfer only some objects, [copy them between project tabs](copy-between-projects.html).
