## Set up

[Launch ForCAD Studio](install.html), then [explore the Chess project](../tutorials/explore-studio.html) to practice selection and inspection.

## Model and mesh

[Find a tool on the Patch ribbon](edit-a-patch.html).

| Goal | Guides |
| --- | --- |
| Construct geometry | [Extrude](extrude-a-profile.html), [revolve](revolve-a-profile.html), [sweep along a curve](sweep-a-profile.html), or [loft between sections](loft-sections.html) |
| Edit controls | [Move a control point](change-control-point.html), [change a weight](change-weight.html), or [edit a shared control](edit-shared-control.html) |
| Edit knots | [Insert a knot](insert-knot.html) or [remove a knot](remove-knot.html) |
| Change a patch representation | [Elevate degree](elevate-degree.html), [reduce degree](reduce-degree.html), [subdivide spans](refine-patch.html), or [set the domain](set-domain.html) |
| Divide or measure geometry | [Split a patch](split-a-patch.html) or [measure a patch](measure-geometry.html) |
| Assemble volumes | [Join two volume patches](join-volume-patches.html) and verify their shared interface |
| Work with a volume mesh | [Mesh one volume](mesh-a-volume.html), [mesh a connected assembly](mesh-a-multipatch.html), or [inspect interior cells](inspect-mesh-interior.html) |

## Share a model or use an agent

- [Save a project](save-project.html), [copy between projects](copy-between-projects.html), or import [FCAD](import-fcad.html) or [IGES](import-iges.html).
- [Choose an export](exchange-files.html#choose-an-export) for geometry, a generated mesh, or a Fortran program.
- [Work with the AI Assistant](../assistant/index.html) to review and run an agent's requested changes.

See [Studio controls](../reference/studio.html) for navigation and keyboard shortcuts and [Studio and Fortran equivalents](../reference/studio-fortran.html) to reproduce an edit in a program.
