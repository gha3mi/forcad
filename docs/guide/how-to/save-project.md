title: Save a project
category: Projects and exchange

1. Activate the project tab you want to save. Choose **Project → Save** (**Ctrl+S**).
2. If prompted for a destination, choose the project folder and enter a name ending in `.fcad`.
3. To create a separate copy on disk, use **Project → Save as** (**Ctrl+Shift+S**) and give it a different name.

Use **Project → Open** to reopen the saved geometry, multipatches, generated meshes, and project settings in Studio.
