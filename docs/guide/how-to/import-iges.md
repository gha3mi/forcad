title: Import IGES geometry
category: Projects and exchange

Use IGES import to bring supported NURBS curves and surfaces into the active project.

1. Choose **Project → Import IGES** and select an `.igs` or `.iges` file.
2. If **IGES source units** appears, choose the unit used by the file. Choose **Keep numeric values** if you want the coordinate numbers to pass through unchanged.
3. Check the status bar for the number of imported objects and any unsupported entities skipped. Inspect the resulting patches in **Scene** and save the project.
