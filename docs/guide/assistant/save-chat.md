title: Save a chat

1. Finish the current request or choose **Stop**.
2. Open **Chat options** (…) in the Assistant header and choose **Save chat**.
3. Check the main status bar for **Chat saved**. After further messages, save again to update the same entry.

For a separate text copy, choose **Chat options → Export chat…**. To continue within ForCAD Studio later, use the [saved chat](reopen-chat.html).
