title: Reopen a chat

1. Open the original project. Check **Project → Folder** if the saved list looks empty. The list belongs to the working folder.
2. In the Assistant, choose **Chat options (…) → Saved chats…**.
3. Select the conversation and choose **Open chat**, or double-click it. If you have unsaved messages in the current chat, respond to the save prompt.
4. Type a follow-up. ForCAD Studio restores the transcript and starts a new agent session on the next message. If the saved provider or model is unavailable, choose an available replacement.

Check the current model before requesting another edit. Reopening a conversation does not restore an earlier version of the geometry.
