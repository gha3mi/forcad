title: Review a tool request

1. Before sending the request, select **Tools: Live** and **Ask for approval** in the Assistant.
2. When **ForCAD Studio approval** appears, read the operation, target, and any values shown. An agent may inspect the project before requesting a change.
3. Choose **Allow once** to run that request or **Deny** to decline it. Watch the activity stream for the result before deciding on the next request.

**Approve for me** lets the agent run Studio changes and write exports without this confirmation. An **Agent permission** prompt comes from the agent's own permission system.

**Stop** interrupts work still in progress. If an edit has already finished, use **Undo** in the main window to reverse the most recent committed project edit. Repeat for any earlier edits you also want to reverse. Undo applies to the project and cannot retract an exported file.
