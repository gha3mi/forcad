title: Delete a saved chat

1. Open the project that owns the conversation.
2. In the Assistant, choose **Chat options (…) → Saved chats…** and select the entry.
3. Choose **Delete chat…**, confirm the title, then choose **Delete chat**.

The entry disappears from the saved list. If it was the chat on screen, the transcript stays open and its status changes to **Chat unsaved**. Choose **New chat** to clear the panel. If prompted, discard the unsaved conversation to avoid saving it again.
