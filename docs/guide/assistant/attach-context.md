title: Attach context to a message

Use the buttons below the message box to identify what the agent should work on.

| To share | Control | What to do |
| --- | --- | --- |
| One or more reference files | **Attach files…** | Select files in the picker. Name each file's role in the message if you attach several. |
| A specific item in the model | **Attach selection** | Select the geometry or feature in ForCAD Studio first, then attach it. |
| The current view | **Attach screenshot** | Frame the relevant detail in the 3D viewport, then capture it. The image excludes the Assistant panel. |

Check the attachments above the message box. Remove any you do not want to send, write the request, and choose **Send**.

For example, attach a drawing and the target selection, then ask “Which dimensions in this drawing are needed to rebuild the selected patch?” File selection accepts any regular file. Choose a vision-capable model when the agent must interpret an image.
