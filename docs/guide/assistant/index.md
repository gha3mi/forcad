The Assistant can use the open ForCAD Studio project to answer questions and request edits. Choose an agent you already use, then decide which changes need your approval.

In [Approve your first edit](first-edit.html), you will rotate a practice model, check the result, and undo the rotation.

## Work on a design

- [Connect an agent](connect-agent.html) to the open project.
- [Attach context to a message](attach-context.html) with a selection, viewport image, or reference file.
- [Review a tool request](review-edits.html) before the agent changes the model.
- [Configure an agent team](configure-team.html) for parallel review and planning.
- [Look up agent roles and skills](roles-and-skills.html) to see who plans, who edits, and which workflows the Assistant can consult.

## Keep a conversation

- [Save a chat](save-chat.html) in the project folder.
- [Reopen a chat](reopen-chat.html) to continue a previous conversation.
- [Delete a saved chat](delete-chat.html) from the project's history.

[Where Assistant data goes](project-data.html) explains what stays in the project and what the chosen provider receives.
