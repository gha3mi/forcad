## Navigate and select

| Viewport action | Input |
| --- | --- |
| Orbit | Right-drag or Shift+middle-drag |
| Pan | Middle-drag |
| Zoom | Scroll |
| Fit all visible geometry | F |
| Fit the selection | Shift+F |
| Add to selection | Shift+click |
| Toggle an item in the selection | Ctrl+click |
| Clear the selection or cancel area selection | Esc |

The viewport selection mode determines what a click can pick, including geometry, control points, or mesh cells. In **Model → Box**, draw left to right to select enclosed items. Draw right to left to include items the box crosses. Use **Lasso** for a freehand region.

In the viewport's **Snap** menu, **Snap to closest point** projects a dragged control point onto a nearby visible patch. [Project a point in Fortran](../fortran/project-a-point.html) shows how to read its surface parameters and physical position.

## Workspace

| Action | Shortcut |
| --- | --- |
| Find a command | Ctrl+K |
| Find objects in Scene | Ctrl+F |
| Toggle Parameter panels | Shift+F11 |
| Toggle Assistant | Ctrl+Shift+A |
| Toggle Canvas only | Ctrl+Shift+F |
| Toggle fullscreen | F11 |

The status bar at the bottom of the workspace gives selection details, command guidance, and feedback after edits.

| Action | Shortcut |
| --- | --- |
| Open a project | Ctrl+O |
| Save | Ctrl+S |
| Save as | Ctrl+Shift+S |
| Copy or paste objects between project tabs | Ctrl+C, Ctrl+V |
| Undo | Ctrl+Z |
| Redo | Ctrl+Shift+Z or Ctrl+Y |
